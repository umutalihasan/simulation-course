# Лабораторная работа №7  
## Моделирование погоды с помощью цепи Маркова

**Проект:** веб-приложение для выполнения лабораторной работы №7.  
**Live Demo:** `umutyagcioglu.com`  
**Реализация:** `HTML`, `CSS`, `JavaScript`.

---

## Назначение работы

Цель работы - реализовать имитационную модель погоды на основе **цепи Маркова с непрерывным временем**.

В модели рассматриваются три состояния:

1. **Ясно**
2. **Облачно**
3. **Пасмурно**

Единица времени - **1 день**.  
Переходы между состояниями задаются **матрицей интенсивностей**.

---

## Функциональные возможности

Приложение поддерживает:

- ввод интенсивностей переходов между состояниями;
- выбор длительности моделирования;
- ввод собственного `seed`;
- построение матрицы интенсивностей `Q`;
- построение встроенной матрицы переходных вероятностей `P`;
- вычисление стационарного распределения `π`;
- моделирование изменения погоды во времени;
- визуализацию траектории состояний;
- сравнение эмпирического и теоретического распределений;
- экспорт итогового отчёта в `.csv`.

## Теоретическая основа

### 1. Матрица интенсивностей

Непрерывная цепь Маркова задаётся матрицей интенсивностей:

```text
Q = [qᵢⱼ]
```

где `qᵢⱼ ≥ 0` при `i ≠ j` - интенсивность перехода из состояния `i` в состояние `j`.

Диагональные элементы вычисляются автоматически:

```text
qᵢᵢ = - Σ qᵢⱼ,  j ≠ i
```

Следовательно, сумма элементов каждой строки матрицы `Q` равна нулю.

### 2. Время пребывания в состоянии

Если система находится в состоянии `i`, то время пребывания в нём распределено по экспоненциальному закону:

```text
Tᵢ ~ Exp(λᵢ),  где λᵢ = -qᵢᵢ
```

Для моделирования используется формула:

```text
T = -ln(U) / λᵢ
```

где `U ∈ (0,1)` - случайное число.

### 3. Матрица переходных вероятностей

После момента выхода из текущего состояния необходимо определить следующее состояние.  
Для этого по матрице `Q` строится встроенная матрица переходных вероятностей:

```text
pᵢⱼ = qᵢⱼ / λᵢ,  i ≠ j
```

При этом:

```text
pᵢᵢ = 0
```

### 4. Стационарное распределение

Теоретическое стационарное распределение `π` находится из системы:

```text
πQ = 0
Σπᵢ = 1
```

Полученные значения показывают, какую долю времени система в среднем проводит в каждом состоянии при большом времени моделирования.

### 5. Критерий `χ²`

Для сравнения эмпирического распределения с теоретическим используется критерий Пирсона:

```text
χ² = Σ (Oᵢ - Eᵢ)² / Eᵢ
```

где `Oᵢ` - наблюдаемое число дней в состоянии `i`,  
`Eᵢ` - ожидаемое число дней по стационарному распределению.

## Описание реализации

В проекте используется собственный мультипликативный конгруэнтный генератор, что позволяет получать воспроизводимые результаты при фиксированном `seed`.

В приложении реализованы:

- ввод шести внедиагональных интенсивностей переходов;
- автоматическое вычисление диагональных элементов матрицы `Q`;
- построение матрицы `P`;
- вычисление стационарного распределения `π`;
- моделирование последовательности погодных состояний;
- отображение траектории по дням;
- вычисление эмпирических частот и временных долей;
- проверка согласия по критерию `χ²`;
- экспорт итоговой статистики в `.csv`.

---

## Описание алгоритмов

### 1. Генерация псевдослучайных чисел

В основе приложения лежит мультипликативный конгруэнтный генератор:

```text
Xₙ₊₁ = (a · Xₙ) mod m
```

После нормировки получается число из интервала `(0,1)`.  
Использование фиксированного `seed` позволяет воспроизводить одинаковые траектории моделирования.

### 2. Алгоритм моделирования непрерывной цепи Маркова

Алгоритм работы модели следующий:

1. Формируется матрица интенсивностей `Q`.
2. По матрице `Q` вычисляется встроенная матрица вероятностей `P`.
3. Находится стационарное распределение `π`.
4. Выбирается начальное состояние.
5. Для текущего состояния генерируется время пребывания по экспоненциальному распределению.
6. По строке матрицы `P` определяется следующее состояние.
7. Процесс повторяется до достижения заданного горизонта моделирования.

### 3. Алгоритм статистической обработки

После завершения моделирования вычисляются:

- число дней в каждом состоянии;
- эмпирические вероятности состояний;
- доля времени, проведённая в каждом состоянии;
- статистика критерия `χ²`.

Затем эмпирическое распределение сравнивается с теоретическим стационарным распределением.
