## Назначение работы

Цель работы - реализовать моделирование случайных величин двух типов:

1. **Дискретная случайная величина**, заданная рядом вероятностей.
2. **Нормальная случайная величина** с параметрами `μ` и `σ²`.

В обоих случаях требуется получить выборку, вычислить эмпирические характеристики, сравнить их с теоретическими значениями и применить критерий `χ²`.

## Теоретическая основа

### 1. Дискретная случайная величина

Пусть заданы вероятности:

```text
p1, p2, p3, p4, p5
```

где

```text
p1 + p2 + p3 + p4 + p5 = 1
```

Генерация выполняется методом обратного преобразования на основе случайного числа `α ∈ [0,1)`.

Теоретические характеристики:

```text
E[X] = Σ xᵢpᵢ
Var[X] = Σ xᵢ²pᵢ - (E[X])²
```

### 2. Нормальное распределение

Во второй части моделируется величина:

```text
X ~ N(μ, σ²)
```

В приложении предусмотрены два способа генерации:

- метод **Box-Muller**;
- метод **inverse CDF**.

Для анализа строится эмпирическая гистограмма и теоретическая кривая плотности.

### 3. Критерий `χ²`

Для проверки согласия используется критерий Пирсона:

```text
χ² = Σ (Oᵢ - Eᵢ)² / Eᵢ
```

где `Oᵢ` - наблюдаемые частоты, `Eᵢ` - ожидаемые частоты.

В проекте используется собственный мультипликативный конгруэнтный генератор, что позволяет получать воспроизводимые результаты при фиксированном `seed`.

В первой части реализованы:

Во второй части реализованы:

- ввод `μ`, `σ²` и `N`;
- генерация выборки из нормального распределения;
- построение гистограммы;
- вычисление эмпирических характеристик;
- сравнение с теоретической кривой и проверка по `χ²`.

## Описание алгоритмов

### 1. Генерация псевдослучайных чисел

В основе приложения лежит мультипликативный конгруэнтный генератор:

```text
Xₙ₊₁ = (a · Xₙ) mod m
```

Полученное значение нормируется к интервалу `(0, 1)`.  
Использование фиксированного `seed` позволяет воспроизводить одинаковые последовательности случайных чисел.

### 2. Алгоритм моделирования дискретной случайной величины

Для заданных вероятностей `p1, ..., p5` строится массив накопленных вероятностей:

```text
F1 = p1
F2 = p1 + p2
...
F5 = 1
```

Далее генерируется число `α ∈ [0,1)` и определяется интервал, в который оно попадает.  
Номер найденного интервала соответствует значению случайной величины.

### 3. Алгоритм моделирования нормального распределения

В приложении предусмотрены два метода:

- **Box-Muller** - преобразование двух независимых чисел `u1, u2 ∈ (0,1)` в стандартные нормальные величины;
- **inverse CDF** - применение обратной функции распределения стандартного нормального закона.

После получения стандартной нормально распределённой величины выполняется переход к общему виду:

```text
X = μ + σZ
```

где `σ = √σ²`.

### 4. Алгоритм статистической проверки

После генерации выборки вычисляются:

- эмпирическое среднее;
- эмпирическая дисперсия;
- частоты наблюдений;
- статистика критерия `χ²`.

Для дискретного случая сравниваются наблюдаемые и ожидаемые частоты исходов.  
Для нормального распределения сравнение выполняется по интервалам гистограммы.
