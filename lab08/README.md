# Лабораторная работа №8
## Моделирование пуассоновского потока запросов на сервер

**Проект:** веб-приложение для моделирования простейшего потока событий.  
**Событие:** поступление запроса на сервер.  
**Реализация:** `HTML`, `CSS`, `JavaScript`.

**Live Demo: https://umutyagcioglu.com**  

---

## Цель работы

Цель работы - смоделировать поток запросов на сервер с помощью модели простейшего пуассоновского потока, определить число запросов за интервал времени `T`, построить эмпирическое распределение и вычислить среднее и дисперсию.

---

## Теоретическая основа

Простейший поток событий обладает следующими свойствами:

- **стационарность**: распределение числа событий зависит только от длины интервала;
- **независимость**: события на непересекающихся интервалах независимы;
- **ординарность**: вероятность одновременного появления двух событий пренебрежимо мала.

В приложении интенсивность `λ` задаётся как число запросов в минуту.  
Интервал `T` можно вводить в минутах или часах. Перед моделированием программа переводит `T` в минуты:

```text
T_minutes = T_minutes
T_minutes = T_hours · 60
```

Если интенсивность потока равна `λ`, то число событий на интервале длины `T` имеет распределение Пуассона:

```text
N(T) ~ Pois(μ)
μ = λ · T_minutes
```

Вероятность получить `k` запросов:

```text
P(N(T) = k) = e^(-μ) · μ^k / k!
```

Для распределения Пуассона:

```text
E[N(T)] = μ
Var[N(T)] = μ
```

## Алгоритм моделирования

В программе моделируются интервалы между соседними событиями. Для простейшего потока они имеют экспоненциальное распределение:

```text
τ = -ln(U) / λ
```

где `U` - равномерная случайная величина на интервале `(0, 1)`.

Алгоритм:

1. Задаются `λ`, `T`, число экспериментов `N` и `seed`.
2. Выбранная единица времени для `T` переводится в минуты.
3. Для каждого эксперимента время устанавливается в `0`.
4. Генерируется интервал до следующего запроса `τ`.
5. Время увеличивается на `τ`.
6. Если новое время не превышает `T_minutes`, число запросов увеличивается на `1`.
7. Процесс повторяется до выхода за границу интервала `T_minutes`.
8. После `N` экспериментов строится эмпирическое распределение числа запросов.

## Что выводит программа

Приложение показывает:

- график эмпирического распределения числа запросов;
- теоретическую кривую распределения Пуассона;
- при больших значениях `μ` соседние значения `k` автоматически объединяются в интервалы, чтобы график оставался читаемым;
- пример траектории накопленного числа запросов на первом интервале;
- теоретическое и эмпирическое среднее;
- теоретическую и эмпирическую дисперсию;
- таблицу вероятностей;
- итоговый вывод;
- экспорт результатов в `.csv`.

## Вывод

При увеличении числа экспериментов эмпирическое распределение числа запросов приближается к теоретическому распределению Пуассона. Также эмпирическое среднее и дисперсия стремятся к одному и тому же значению:

```text
μ = λ · T_minutes
```
